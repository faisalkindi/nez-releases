# Nez website screenshots

Real Nez window (build 154.0.8037.57), captured over CDP at 2x from a throwaway demo profile (public sites only, nothing personal), then framed with rounded corners, a soft shadow and a gradient "wallpaper" (no real Mica on the capture desktop). Every PNG has a `-1600.png` copy at 1600 px wide.

Demo profile: spaces Personal, Work, Travel (emoji icons, gradient themes); 8 Essentials (GitHub, Wikipedia, MDN, Hacker News, YouTube, Stack Overflow, OpenStreetMap, NASA); pinned tabs and a "Reading" folder in Work; open tabs with readable titles. The Work space is the active one in all shots.

| File | Shows |

Notes: sidebars are tinted by the Work space's blue gradient theme. Light-mode shots use the same theme, so the sidebar looks similar in both. Page content is live web content from the day of capture (2026-10-05).
